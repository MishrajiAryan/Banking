# Banking Application

A comprehensive banking system built with Python and Flask for managing financial transactions and user accounts.

## Features

- User account management
- Transaction processing
- Government schemes integration (161 questions)
- Secure banking operations
- Database-driven architecture
- Web-based interface

## Tech Stack

- **Backend**: Python, Flask
- **Frontend**: HTML, CSS
- **Database**: SQLite
- **Additional**: Python caching system

## Installation

1. Clone the repository:
```bash
git clone https://github.com/MishrajiAryan/Banking.git
cd Banking
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the application:
```bash
python app.py
```

4. Open your browser and navigate to `http://localhost:5000`

## Usage

- Access the banking system through the web interface
- Create and manage user accounts
- Process transactions securely
- Access government schemes information

## Project Structure

```
Banking/
├── app.py              # Main Flask application
├── index.html          # Frontend interface
├── requirements.txt    # Python dependencies
├── db/                 # Database files
└── __pycache__/       # Python cache files
```
